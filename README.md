# E-Commerce Flutter App (Training Project)

## 📌 Overview

This repository contains a Flutter-based mobile application developed as a training project.
The main focus of this project is practicing how to integrate a Flutter application with **Firebase services**, especially authentication.

The project is still under development and will be continuously improved.

---

## 🚀 Current Features

### 🔐 Authentication Module

* User Login screen
* User Signup screen
* Firebase Authentication integration (in progress / basic setup)
* Form validation for input fields

---

## 🛠️ Tech Stack

* Flutter (Dart)
* Firebase

  * Firebase Authentication
  * (Future: Firestore / Database integration)
* Android Studio / VS Code

---

## 📂 Project Structure (Highlights)

* `lib/features/auth/` → Contains Login & Signup screens
* `lib/features/home/` → Home screen UI
* `lib/features/cart/` → Cart screen (UI only for now)
* `lib/features/categories/` → Categories screen
* `lib/features/profile/` → Profile screen
* `firebase_options.dart` → Firebase configuration file

---

## 📈 Project Status

This project is currently in **active development**:

* Authentication module implemented
* Firebase connection established
* More features will be added gradually (cart logic, backend integration, product management, etc.)

## 🎯 Goal of the Project

The goal is to:

* Learn how to integrate Flutter apps with Firebase
* Build a full e-commerce app structure
* Practice clean architecture and feature-based project organization
* Improve real-world mobile development skills
